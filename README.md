# 불빛 우체국 (Lightpost)

> 누가 봐도 난장판인 섬마을 우체국 숙직실을 **줍고, 닦고, 내 마음대로 정리해서** 불이 켜진 나만의 방으로 만드는 혼자 하는 청소 힐링 웹게임

- **소개 페이지:** https://아이디.github.io/lightpost/ ← GitHub Pages 주소로 바꿔 주세요
- **바로 플레이:** https://아이디.github.io/lightpost/play.html
- **장르:** 스토리형 청소 힐링 게임 (싱글플레이)
- **플랫폼:** PC 웹 브라우저 (설치 · 회원가입 없음)
- **플레이 시간:** 한 판 5분
- **상태:** 개발 중 (챕터 1 우체국 숙직실, 챕터 2 빵집 부엌)

---

## 게임 소개

- **배경:** 안개 낀 섬마을 등불섬. 이 섬의 등대는 사람들 사이에 전해진 편지로 빛나요.
- **문제:** 편지가 끊기자 집집마다 난장판이 되고 불빛이 꺼졌어요.
- **플레이어:** 새 우체국장으로 섬에 와서, 내가 지낼 숙직실부터 치우기 시작해요.
- **목표:** 방을 치울수록 밝아지고, 밝기 100%가 되면 방에 불이 켜져요.

## 조작법

| 도구 | 키 | 하는 일 |
|---|---|---|
| 줍기 | `1` | 쓰레기를 누르면 봉투에 쏙, **누른 채 쓸면 여러 개가 한꺼번에**. 물건은 끌어서 칸에 놓기 |
| 닦기 | `2` | 얼룩 위를 누른 채 문지르면 조금씩 지워짐 (창문도 닦을 수 있음) |
| 손전등 | `3` | 남은 쓰레기와 얼룩이 반짝여서 찾기 쉬움 |

- **봉투:** 20개가 차면 오른쪽 아래 봉투를 눌러 비워요.
- **도구 자동 전환:** 줍기 도구로 얼룩을 누르면 닦기로, 닦기 도구로 쓰레기를 누르면 줍기로 저절로 바뀌어요.
- **처음 30초 안내:** 처음 시작하면 줍기 → 닦기 → 정리를 한 번씩 따라 해 봐요 (건너뛰기 가능).
- **냄새 나는 더미:** 여러 번 눌러야 없어지고, 밑에 무언가 숨어 있어요.
- **거울:** 렌즈 조각을 빈 받침대에 끼운 뒤 누르면 빛의 방향이 바뀌어요.
- **딩 콤보:** 같은 종류 물건을 같은 줄 이웃 칸에 나란히 두면 '딩!'
- 줍기 · 닦기 · 정리는 **순서 없이** 자유롭게 섞어서 할 수 있어요. 시간 제한과 게임 오버는 없어요.

## 화면 구성

```
S1 시작 ─▶ 등불섬 지도 ─▶ 오프닝 ─▶ S2 플레이 ─▶ S4 결과 ─▶ 다음 편지 ─▶ 지도
                                          │               └─▶ S5 내 방 꾸미기 (우체국)
                                          └─▶ S3 팝업 (쪽지 · 렌즈 조각 · 우표)
```

| 화면 | 내용 |
|---|---|
| S1 시작 | 제목, 시작하기 / 이어하기, 저장된 진행 상황, 깜빡이는 등대 |
| 등불섬 지도 | 우체국 · 빵집 · 창고 · 작업실 · 등대. 치운 집은 불이 켜지고, 다음 집이 열림. 렌즈 조각이 모일수록 등대가 밝아짐 |
| S2 플레이 | 밝기 게이지, 쓰레기 · 얼룩 · 정리 개수, 도구 막대, 봉투 |
| S3 팝업 | 숨은 쪽지(손글씨 편지), 등대 렌즈 조각, 개국 기념 우표 |
| S4 결과 | 손잡이로 보는 청소 전/후 비교, 별 3개, 우표첩, 편지 열어 보기 |
| S5 내 방 | 소품 7개로 꾸미기, 사진 찍기(그림 파일 저장), 꾸민 모습 저장 |

## 핵심 기능

| | 챕터 1 우체국 숙직실 | 챕터 2 빵집 할머니의 부엌 |
|---|---|---|
| 쓰레기 | 컵라면 · 캔 · 휴지 등 34개 + 더미 2개 | 탄 빵 · 달걀 껍데기 · 밀가루 봉지 등 30개 + 더미 2개 |
| 얼룩 | 9개 (바닥 7 · 벽 곰팡이 · 창문) | 9개 (기름때 · 밀가루 · 잼 · 그을음 · 오븐 유리) |
| 정리 | 물건 10개 · 칸 15개 | 물건 10개 · 칸 13개 |
| 빛 퍼즐 | 창문 달빛 + 거울 1개 | 오븐 불빛 + 거울 2개 |
| 숨은 것 | 윤 국장의 쪽지, 렌즈 조각, 개국 기념 우표 | 손주에게 쓴 편지, 렌즈 조각, 빵 축제 기념 우표 |
| 다 치우면 | 마을 고양이가 찾아옴 | 순자 할머니가 찾아와 한마디 (정리한 물건에 따라 대사가 바뀜) |

- **얼룩 닦기:** 문지를 때 거품과 '뽀득' 소리, 단단한 얼룩일수록 오래 걸림
- **자유 정리:** 가까운 빈칸으로 자동 맞춤, 같은 종류를 나란히 두면 '딩' 콤보
- **불빛 장치:** 창문 · 오븐 유리를 닦으면 빛이 들어오고, 거울로 꺾어 숨은 우표를 찾음
- **쓸어 담기:** 누른 채 쓸면 지나간 쓰레기가 모두 봉투로, 4개 이상이면 '싹쓸이!'
- **밝기 단계:** 30 · 60 · 90%마다 방이 점점 따뜻한 빛으로 바뀜
- **배경 소리:** 잔잔한 파도 소리와 가끔 울리는 풍경 소리
- **파리:** 쓰레기를 거의 다 치우면 창밖으로 날아감
- **저장:** 치운 곳, 별, 우표, 렌즈 조각, 꾸민 내 방이 브라우저에 저장됨 (지도에서 기록 지우기 가능)
- **밝기 게이지:** 치울수록 방의 어둠이 실제로 걷힘
- **전/후 비교:** 결과 화면에서 처음의 난장판과 치운 방을 겹쳐 보기
- **내 방 꾸미기:** 러그 · 꼬마전구 · 화분 · 등대 포스터 · 우표 액자 · 스탠드 · 빵 바구니(빵집을 치우면 할머니가 보내 줌)

### 밝기 계산

| 항목 | 비중 |
|---|---|
| 쓰레기 치우기 | 35% |
| 얼룩 닦기 | 45% |
| 물건을 칸에 정리하기 | 20% |

- 바닥 아무 곳에나 놓아도 되지만, 정리 점수는 칸에 놓았을 때만 올라요.

### 별 3개 기준

- ★ 클리어 (밝기 100%)
- ★ 숨은 쪽지 찾기
- ★ 빛으로 숨은 우표 찾기

## 기술

- **HTML · CSS · JavaScript** (외부 라이브러리 없음, 게임은 `play.html` 파일 하나)
- **저장:** 브라우저 localStorage + Firebase (Authentication · Firestore, 선택)
- **그림:** SVG를 코드로 그린 2.5D 아이소메트릭 방
- **소리:** Web Audio API로 직접 합성 (음원 파일 없음)
- **글꼴:** Google Fonts의 고운돋움, 나눔손글씨 펜
- **배포:** GitHub Pages

## 데이터 저장 (Firebase, 선택)

`play.html` 아래쪽 `FIREBASE_CONFIG = null` 자리에 Firebase 설정값을 붙여 넣으면 켜져요. 비워 두면 지금처럼 브라우저에만 저장돼요.

| 저장하는 것 | Firestore 위치 | 언제 |
|---|---|---|
| 게임 진행 (치운 곳, 별, 우표, 렌즈, 내 방) | `saves/{사용자 ID}` | 진행이 바뀔 때마다 |
| 플레이 기록 (방, 걸린 시간, 단계별 시간, 별, 찾은 것, 콤보 수, 최대 싹쓸이 수) | `plays` | 방을 다 치울 때마다 |
| 피드백 ("다음 방도 치워 보고 싶나요?", 소감) | `feedback` | 결과 화면에서 보낼 때 |

- **로그인:** 처음엔 로그인 없이(익명) 저장되고, 시작 화면의 **구글로 로그인**을 누르면 다른 기기에서도 이어할 수 있어요.
- **개인정보:** 이름 · 연락처는 저장하지 않고, Firebase가 만든 사용자 ID만 저장해요.
- **보안 규칙:** `firestore.rules`를 Firestore 규칙에 붙여 넣으세요. 각자 자기 진행만 읽고 쓸 수 있고, 기록 · 피드백은 추가만 할 수 있어요.
- **결과 보기:** Firebase 콘솔 → Firestore Database → `plays`, `feedback` 컬렉션

## 실행 방법

## 비슷한 게임과 다른 점

- **PowerWash Simulator:** 청소의 쾌감은 같지만, 불빛 우체국은 치운 방이 **내 방**이 되어 꾸미기까지 이어져요.
- **Unpacking:** 물건 정리로 이야기를 전하는 점은 같지만, 불빛 우체국은 정답 자리 없이 **어디에 놓아도** 돼요.
- **가장 큰 차별점:** 치울수록 방이 밝아지고, 그 **빛으로 숨은 것을 찾는** 불빛 장치
