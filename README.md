# 불빛 우체국 (Lightpost)

> 누가 봐도 난장판인 섬마을 우체국 숙직실을 **줍고, 닦고, 내 마음대로 정리해서** 불이 켜진 나만의 방으로 만드는 혼자 하는 청소 힐링 웹게임

- **플레이:** https://아이디.github.io/lightpost/ ← GitHub Pages 주소로 바꿔 주세요
- **장르:** 스토리형 청소 힐링 게임 (싱글플레이)
- **플랫폼:** PC 웹 브라우저 (설치 · 회원가입 없음)
- **플레이 시간:** 한 판 10~15분
- **상태:** MVP (챕터 1의 첫 방 하나)

---

## 게임 소개

- **배경:** 안개 낀 섬마을 등불섬. 이 섬의 등대는 사람들 사이에 전해진 편지로 빛나요.
- **문제:** 편지가 끊기자 집집마다 난장판이 되고 불빛이 꺼졌어요.
- **플레이어:** 새 우체국장으로 섬에 와서, 내가 지낼 숙직실부터 치우기 시작해요.
- **목표:** 방을 치울수록 밝아지고, 밝기 100%가 되면 방에 불이 켜져요.

## 조작법

| 도구 | 키 | 하는 일 |
|---|---|---|
| 줍기 | `1` | 쓰레기를 누르면 봉투에 쏙. 물건은 끌어서 선반 · 서랍장 · 책상 위 칸에 놓기 |
| 닦기 | `2` | 얼룩 위를 누른 채 문지르면 조금씩 지워짐 (창문도 닦을 수 있음) |
| 손전등 | `3` | 남은 쓰레기와 얼룩이 반짝여서 찾기 쉬움 |

- **봉투:** 10개가 차면 오른쪽 아래 봉투를 눌러 비워요.
- **냄새 나는 더미:** 여러 번 눌러야 없어지고, 밑에 무언가 숨어 있어요.
- **거울:** 렌즈 조각을 상 위 받침대에 끼운 뒤 누르면 빛의 방향이 바뀌어요.
- 줍기 · 닦기 · 정리는 **순서 없이** 자유롭게 섞어서 할 수 있어요. 시간 제한과 게임 오버는 없어요.

## 화면 구성

```
S1 시작 ─▶ 오프닝 ─▶ S2 플레이 ─▶ S4 결과 ─▶ S5 내 방 꾸미기 ─▶ S1 시작
                         │
                         └─▶ S3 팝업 (쪽지 · 렌즈 조각 · 우표)
```

| 화면 | 내용 |
|---|---|
| S1 시작 | 제목, 시작하기, 소리 켜기 · 끄기, 깜빡이는 등대 |
| S2 플레이 | 밝기 게이지, 쓰레기 · 얼룩 · 정리 개수, 도구 막대, 봉투 |
| S3 팝업 | 숨은 쪽지(손글씨 편지), 등대 렌즈 조각, 개국 기념 우표 |
| S4 결과 | 손잡이로 보는 청소 전/후 비교, 별 3개, 우표첩, 다음 편지 |
| S5 내 방 | 소품 6개로 꾸미기, 사진 찍기(그림 파일 저장) |

## 핵심 기능

- **쓰레기 줍기:** 쓰레기 58개 + 냄새 나는 더미 2개
- **얼룩 닦기:** 얼룩 9개 (바닥 7 · 벽 곰팡이 1 · 창문 1), 문지를 때 거품과 '뽀득' 소리
- **자유 정리:** 물건 10개, 수납 칸 15개, 가까운 빈칸으로 자동 맞춤
- **불빛 장치:** 창문을 닦으면 달빛이 들어오고, 거울로 꺾으면 벽 틈의 우표를 찾음
- **밝기 게이지:** 치울수록 방의 어둠이 실제로 걷힘
- **전/후 비교:** 결과 화면에서 처음의 난장판과 치운 방을 겹쳐 보기
- **내 방 꾸미기:** 러그 · 꼬마전구 · 화분 · 등대 포스터 · 우표 액자 · 스탠드

### 밝기 계산

| 항목 | 비중 |
|---|---|
| 쓰레기 치우기 | 35% |
| 얼룩 닦기 | 45% |
| 물건을 칸에 정리하기 | 20% |

- 바닥 아무 곳에나 놓아도 되지만, 정리 점수는 칸에 놓았을 때만 올라요.

### 별 3개 기준

- ★ 클리어 (밝기 100%)
- ★ 숨은 쪽지 찾기
- ★ 벽 틈의 우표 찾기

## 기술

- **HTML · CSS · JavaScript** (외부 라이브러리 없음, `index.html` 파일 하나)
- **그림:** SVG를 코드로 그린 2.5D 아이소메트릭 방
- **소리:** Web Audio API로 직접 합성 (음원 파일 없음)
- **글꼴:** Google Fonts의 고운돋움, 나눔손글씨 펜
- **배포:** GitHub Pages

## 실행 방법

- **온라인:** 위의 GitHub Pages 주소로 접속
- **내 컴퓨터:** `index.html`을 내려받아 브라우저로 열기
  - 글꼴은 인터넷에 연결되어 있어야 불러와져요.

## 이번 MVP에 없는 것 (나중에 추가)

- 마을 지도와 챕터 2~5 (빵집, 창고, 화가 작업실, 등대)
- 등대 렌즈 조각 5개를 모아 등대에 불을 켜는 엔딩
- 진행 저장 (지금은 새로고침하면 처음부터 시작)
- 휴대폰 세로 화면 최적화, 배경음악

## 비슷한 게임과 다른 점

- **PowerWash Simulator:** 청소의 쾌감은 같지만, 불빛 우체국은 치운 방이 **내 방**이 되어 꾸미기까지 이어져요.
- **Unpacking:** 물건 정리로 이야기를 전하는 점은 같지만, 불빛 우체국은 정답 자리 없이 **어디에 놓아도** 돼요.
- **가장 큰 차별점:** 치울수록 방이 밝아지고, 그 **빛으로 숨은 것을 찾는** 불빛 장치
